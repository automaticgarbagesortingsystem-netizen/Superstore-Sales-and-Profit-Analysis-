# Superstore Sales and Profit Analysis using Power BI

# Introduction
This project explores Superstore sales and profit to help management understand performance across regions, categories and customer segments
Problem Statement
The business needs to understand which regions, categories and customer segments are driving sales and profitability, and where performance can be improved.

# Business Questions
•	Which region generated the highest sales?
•	Which categories are most profitable?
•	Where are sales high but profit low?
•	How did sales change over time?
•	Who are our top customers?

# Dataset Overview
The dataset contains 9994 records of orders that were made between 2014 and 2017. Some of the columns include OrderID	OrderDate	ShipDate	ShipMode	Sales	Quantity Profit	CustomerID	CustomerName	Segment	Country	City	StatePostalCode	Region	ProductID	Category	SubCategory	ProductName
The orderdate describes the date which the order was made
Sales is the total amount of revenue generated from each order
